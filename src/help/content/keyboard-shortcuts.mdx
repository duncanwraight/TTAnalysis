The tracker and the sweep page take the keyboard on screens wider than 768 pixels. Keys don't work while you're typing in a box, and they're shown on screen as you go, so you don't need to learn them first.

## Tracker

Before a point:

| Key | What it does |
| --- | --- |
| <kbd>1</kbd> | The player won the point |
| <kbd>2</kbd> | The opponent won the point |
| <kbd>Z</kbd> | Undo the last point, or the last End set |

During a point, only the shot list waiting for a shot listens: the winning shot first, then the losing shot.

| Key | What it does |
| --- | --- |
| <kbd>←</kbd> <kbd>→</kbd> | Previous or next shot category |
| <kbd>1</kbd> to <kbd>9</kbd> | Choose a shot by its number in the list |
| <kbd>F</kbd> or <kbd>B</kbd> | Forehand or backhand, which picks the chosen shot |
| <kbd>U</kbd> | Tick or untick unforced error |
| <kbd>L</kbd> | Tick or untick lucky |
| <kbd>Backspace</kbd> | Change the winning shot |
| <kbd>Esc</kbd> | Cancel the point |

So the third shot in the open tab, played on the forehand, is <kbd>3</kbd> then <kbd>F</kbd>. The point saves when the losing shot is picked, so tick <kbd>U</kbd> or <kbd>L</kbd> before that.

## Sweep page

| Key | What it does |
| --- | --- |
| <kbd>Y</kbd> | Yes |
| <kbd>N</kbd> or <kbd>Space</kbd> | No, next point |
| <kbd>Backspace</kbd> | Back a point |

See [Mark unforced errors and attacks](/help/unforced-errors-and-attacks) for how sweeps work.
