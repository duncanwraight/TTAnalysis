The tracker opens when you create a match, and again from **Continue entering points** on the match list. Have the video open beside it. Everything saves as you go, so you can leave at any point and pick up where you stopped.

## Who won

The score is two big buttons, one for each player. Tap the side of whoever won the point. **Serving** shows who's serving, which the app works out from the first server you picked. Under the score, a strip shows each point of the set in blue (to the player) or orange (to the opponent).

## The winning and losing shots

Two shot lists open: the winning shot first, then the losing shot.

- **Winning shot:** the last shot of the player who won the point.
- **Losing shot:** the last shot of the player who lost it. Either the one that set up the winner (they push, you loop past them) or the one that missed (you loop, they miss the block).

Shots are grouped by category in tabs. Each shot has **FH** and **BH** buttons for forehand and backhand: pick the shot by tapping the hand. Each list remembers the last tab you used, so a run of similar points doesn't need the tab picking again.

The point saves as soon as you pick the losing shot. On a phone the losing shot list appears once the winning shot is picked, and the winning shot folds away with a **Change** button.

Some shots only make sense one way round:

- **Serve** can only be picked for the player who served.
- **Service fault** is only ever the receiver's winning shot. Picking it saves the point straight away, with no losing shot. The analysis counts it against the server as an unforced error.

## Lucky and unforced

Above the shot lists are two ticks. Set them before you pick the losing shot, because that saves the point.

- **Lucky** when the winning shot hit the net or the edge.
- **Unforced error** when the losing shot was one the player would expect to make. See [Unforced error](/help/glossary#unforced-error).

You don't have to tick either while entering. A [sweep](/help/unforced-errors-and-attacks) afterwards is often quicker and more accurate, because you're only watching for one thing.

**Cancel point** clears the point without saving it.

## Undo and End set

**Undo point** removes the last point you entered, even if it finished a set. Press it again to go further back. Undo only removes points newest first, so going back to an old point removes everything after it.

**End set** ends the set early and gives it to whoever is ahead. Use it when the video cuts out before the end of a set, or a set was conceded. It can't be used with the scores level. Straight after End set, the button reads **Undo End Set**, which reopens the set and keeps its points.

Both buttons are greyed out while a point is half entered. Finish or cancel the point first.

## When a set or the match ends

A set ends on its own at 11 with a two-point lead, and the match ends as soon as someone has won enough sets. Sets that wouldn't change the result aren't played. The match complete screen shows the set scores and links to the analysis and the points editor. If it ended by mistake, the link under the buttons undoes the last point and reopens the match.

## When the video and the score drift apart

Check the tracker's score against the video every so often. The serve is a quick check: if the tracker says one player is serving and the video shows the other, a point has been missed or entered twice.

- **A missed or extra point in the set you're entering:** use Undo to go back to before it, then enter the points again from there.
- **A point with the wrong winner or the wrong shot:** carry on, and fix it afterwards in the [points editor](/help/fix-a-point). Fixing a winner there needs the set to still add up, which usually means changing two points.
- **A missed or extra point in an earlier set:** points can't be added or removed once a set is finished. Undo would remove everything since. If it's one point, it's usually best to leave it: it moves the counts by one.

## On a laptop

On a screen wider than 768 pixels the tracker takes the keyboard: <kbd>1</kbd> or <kbd>2</kbd> for who won, then the arrow keys and a shot's number for the shots. The keys are shown on screen as you go. See [Keyboard shortcuts](/help/keyboard-shortcuts).
